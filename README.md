Chào mừng bạn đến với trang cá nhân GitHub của mình! 💜
Mình là sinh viên ngành Công nghệ thông tin tại Trường Đại học Tài nguyên và Môi trường TP.HCM (HCMRE), có niềm đam mê với phát triển phần mềm, ứng dụng web và khám phá các công nghệ mới. Đây là nơi mình ghi lại hành trình học tập, các bài tập học phần và các dự án lập trình thực tế.

---

### 🌱 Giới thiệu về mình
- 🎓 **Ngành học:** Công nghệ Thông tin (Lớp: 12_ĐH_CNTT1)
- 💻 **Lĩnh vực quan tâm:** Phát triển Web, Kỹ thuật phần mềm và Ứng dụng GIS
- 📚 **Đang học:** Lập trình hướng đối tượng nâng cao & Phát triển ứng dụng doanh nghiệp (OOSD)
- 🚀 **Mục tiêu:** Xây dựng các giải pháp phần mềm ổn định, thân thiện với người dùng và không ngừng nâng cao kỹ năng lập trình
- 📂 **Kho lưu trữ:** Các bài thực hành trên lớp, đồ án học phần và các dự án cá nhân

---

### 🛠️ Công nghệ & Công cụ
* **Ngôn ngữ lập trình:** Java, C#, Python, JavaScript/TypeScript, Dart
* **Backend & Web Frameworks:** Spring Boot (MVC, REST APIs), ASP.NET Core, Django, Thymeleaf
* **Frontend:** React.js, HTML5, CSS3, Bootstrap 5, Tailwind CSS
* **Lập trình di động:** Flutter & Dart
* **GIS & Viễn thám:** QGIS, ArcGIS, ENVI, Google Earth Engine, Leaflet, OpenStreetMap
* **Cơ sở dữ liệu & Công cụ:** Microsoft SQL Server, PostgreSQL (PostGIS), MySQL, Git, VS Code, SSMS, pgAdmin

### 📚 OOSD — Phát triển phần mềm hướng đối tượng
Phần này tổng hợp các bài tập và phòng thí nghiệm thực hành cho học phần OOSD, thể hiện quá trình phát triển qua từng giai đoạn của các hệ thống quản lý doanh nghiệp khác nhau.

| Bài Lab | Chủ đề | Mô tả & Công nghệ cốt lõi |
| :--- | :--- | :--- |
| **LAB 1** | Nền tảng cơ bản | Thực hành các khái niệm cơ bản, cú pháp và bài tập lập trình có cấu trúc. |
| **LAB 2** | Quản lý Thư viện | Xây dựng hệ thống quản lý thư viện tập trung vào các nguyên lý thiết kế hướng đối tượng, quản lý sách, độc giả và giao dịch mượn/trả. |
| **LAB 3** | Hệ thống Quản lý Khách sạn | Phát triển ứng dụng quản lý khách sạn toàn diện xử lý đặt phòng, nhận/trả phòng và dịch vụ khách hàng (Java, Spring Boot, SQL Server). |
| **LAB 4** | eShopping (Hệ thống Thương mại điện tử) | Thiết kế và thực hiện các tính năng cho nền tảng mua sắm trực tuyến, bao gồm danh mục sản phẩm, giỏ hàng, xác thực người dùng và xử lý đơn hàng. |
| **LAB 5** | Hệ thống Quản lý Công ty Du lịch | Dự án nâng cao mới nhất có giao diện web giả lập ứng dụng desktop (Spring Boot, Thymeleaf, Bootstrap 5, SQL Server) quản lý tour, hành trình, đặt vé, đăng ký đoàn, phân công nhân sự và thống kê lương. |

🔗 **Kho lưu trữ:** https://github.com/baoanh23-lab/OOSD.git

### 🚀 Dự án nổi bật
* 🚌 **Hệ thống Quản lý Công ty Du lịch (LAB 5):** Hệ thống quản lý du lịch toàn diện từ quản lý tour, điểm dừng, phương tiện, hướng dẫn viên, đăng ký khách lẻ/đoàn cho đến tính lương và thống kê tổng hợp.
* ☕ **MaoCoffee:** Ứng dụng web quản lý quán cà phê sử dụng Spring Boot, SQL Server và Thymeleaf.
* 📰 **3BÁO:** Hệ thống quản lý tin tức hiện đại được xây dựng bằng Spring Boot, React và PostgreSQL.
* 🗺️ **CafeHouse:** Hệ thống WebGIS quản lý chuỗi cửa hàng cà phê tích hợp Django, PostGIS và bản đồ Leaflet.
